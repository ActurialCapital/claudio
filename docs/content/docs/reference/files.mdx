All under `~/.config/claudio`, or `$XDG_CONFIG_HOME/claudio` when that is set.

| Path | What it is |
|---|---|
| `config.json` | your settings |
| `secrets.json` | your API keys, mode 600 |
| `prompt.md` | the persona, copied from the package on first run |
| `transcripts/YYYY-MM-DD.md` | every conversation, one file a day |
| `session` | the remembered brain session and when it was saved |
| `brain.log` | the brain's errors, appended |
| `helper.log` | the echo canceller's errors, rewritten each run |
| `bin/claudio-audio` | the echo canceller, built from `audio.swift` |

Elsewhere:

| Path | What it is |
|---|---|
| `.claudio.json` in the current directory | per-project setting overrides |
| `~/.claude/settings.json` | where the hooks are installed |
| `~/.claude/settings.json.bak-claudio` | the backup taken before each install or uninstall |
| `/tmp/claudio-<uid>.sock` | the socket the hooks report to, while claudio runs |

## What the brain may do

The brain is a `claude -p` process with a short list of allowed tools. It runs with no settings sources, so your own Claude Code settings and hooks do not apply to it.

- **Read** files, and search with **Grep** and **Glob**. It may not read `secrets.json`.
- **git**: `status`, `log`, `diff`, `branch`.
- **cmux**: `agent message`, `surface list`, `read-screen`, `new-workspace`, `new-split`, `new-surface`.
- **claudio set**, to change a setting when you ask.

Nothing else: no edits, no other shell commands. Work goes to your sessions.
