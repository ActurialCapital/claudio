Say “slash” and a command, such as “slash stop”, or type `/stop` and press <kbd>Enter</kbd>. claudio acts on a slash command itself; the brain never sees it.

## Slash commands

| Command | Argument | Effect |
|---|---|---|
| `stop` | | cuts the current reply |
| `permissions` | `skip`, or `ask` | `skip` asks “Skip every permission check until you quit?” and a yes restarts the brain with none; `ask` turns them back on. Never saved |
| `clear` | | forgets the conversation, restarts the brain fresh, and says “Fresh start.” |
| `mute` | | says “Muted.”, then ignores everything you say except “slash unmute”, and narrates no session reports |
| `unmute` | | says “I'm listening again.” |
| `status` | | says the orchestrator, model, effort, Aura voice and memory |
| `help` | | says the list of commands |
| `quit` (or `exit`) | | says “Bye.” and quits, as <kbd>Ctrl</kbd>+<kbd>C</kbd> does once it is said |
| `model` | `default`, `sonnet`, `opus` or `haiku` | saves the model; the brain restarts and says it is back |
| `effort` | `low`, `medium` or `high` | saves the effort; the brain restarts and says it is back |
| `style` | `plain`, `brief` or `caveman` | saves the [style](/docs/configure/persona#switch-the-style); the brain restarts and says it is back |
| `voice` | an Aura-2 name, such as `thalia` | saves `aura-2-thalia-en` and confirms in the new voice: “Thalia from now on.” Any other word, or none, lists the voices |
| `colors` (or `colours`, “code colors”) | `on`, `off`, or none to flip | saves `code_colors`: code blocks highlighted, or as plain text; says “Code colours off.” |
| `layout` | `inline`, `split`, or none to flip | saves `layout`: your turns as `› text`, or on the right; says “Layout split.” |
| `name` | one to three words, such as `roger` | saves `name`: what it answers to under `address_me` and calls itself; the brain restarts and says “Back, as Roger.” Alone, it says the name it has |

The `model`, `effort`, `style`, `voice`, `colors`, `layout` and `name` changes are saved to `config.json`, like [`claudio set`](/docs/reference/cli#claudio-set-key-value). `clear` does not delete the transcripts.

While muted, typed lines still work as turns.

### How a spoken command is recognised

- “slash” must start the turn, after at most two of: um, uh, ok, okay, so, hey, and, well, please, yeah, right, now, “slash”, or a command name (an echoed “mute slash mute”). “okay, slash stop” works, “could you add a slash command” does not.
- The command runs when your turn ends, never on an early start.
- With `address_me` on, start with the name: “claudio, slash stop”.

### When a command is not understood

| You say | You hear |
|---|---|
| a model or effort it does not know | “I don't know model fast. Choose default, sonnet, opus, haiku.” |
| a command name heard in pieces or slightly off, such as “slash e fort” | read as the nearest command: effort |
| a voice name alone, such as “slash pandora” | sets that voice |
| “slash model” or “slash effort” with nothing after it | says the choices: “Effort is low, medium, high.” |
| a voice it does not know, or none | “Banana is not recognised as a voice. The voices are as follows:”, then every Aura-2 voice as a list on screen, not read aloud. Nothing is saved |
| a style it does not know | “I don't know style …. Choose plain, brief, caveman.” A near miss like “pavement” counts as caveman |
| an unknown command | “I don't know slash …”, then the help list |

## Keys

| Key | Effect |
|---|---|
| <kbd>Enter</kbd> on an empty line | cuts the reply; with push to talk, opens the mic when it is closed |
| a typed line, then <kbd>Enter</kbd> | a turn, as if you had said it; while you type, the line shows on the state line as `› …▏` |
| <kbd>Backspace</kbd> · <kbd>Ctrl</kbd>+<kbd>U</kbd> | deletes a character · the whole typed line |
| `/` and a command, then <kbd>Enter</kbd> | a slash command |
| <kbd>Ctrl</kbd>+<kbd>C</kbd>, or `/quit` | quits |

## Backchannels

When you talk over a reply with `barge_in` on, the reply pauses. When your turn ends, it counts as a backchannel, and the reply carries on from the sentence it was on, if it is fewer than two words or made only of these words:

```text
yeah yes yep ok okay mm mhm hmm uh huh um right sure oh ah no
```

Anything else cuts the reply and becomes your next turn. If you say nothing for 3 seconds after the pause, the reply carries on too.

## The handover marker

Work the brain hands to a session starts with this marker, so the session knows the words are yours:

```text
[spoken by the user, transcribed by claudio]
```

The message goes through `cmux agent message` with `--from Voice`.
