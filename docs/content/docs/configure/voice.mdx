To change the voice, say “slash voice asteria”. The mouth is the part that speaks: it turns each sentence of a reply into speech as soon as the brain has written it. Deepgram Aura is the default mouth. ElevenLabs is the paid alternative, and Kokoro runs on your Mac with no key.

## Pick a Deepgram Aura voice

Any Aura-2 voice works. Setup offers these six, and `aura-2-orion-en` is the default:

<Voices />

Change it by voice, or from the shell with the full name:

<Tabs items={['By voice', 'From the shell']}>
<Tab value="By voice">

```transcript
› slash voice asteria
· /voice asteria
⚙ settings reloaded
◆ Asteria from now on.
```

The short name is enough: “asteria” becomes `aura-2-asteria-en`. The confirmation already speaks in the new voice.

</Tab>
<Tab value="From the shell">

```bash
claudio set voice aura-2-asteria-en
```

The change applies from the next reply, not the one being spoken.

</Tab>
</Tabs>

### Pick one by how it sounds

Say what you want instead of a name: “slash voice a British woman”, “slash voice deep male”, “slash voice calm storytelling”. Each Aura voice carries Deepgram's own description of it: its accent, its age, words like `warm`, `raspy` or `baritone`, and what it suits, such as `storytelling` or `customer service`. “Woman” and “female” mean `feminine`, “man” and “male” mean `masculine`.

```transcript
› slash voice calm
· /voice calm
◆ 6 voices are calm:
  - athena: American, mature, feminine, calm, smooth, professional, storytelling
  …
```

When one voice has every feature you said, it becomes the voice, as if you had said its name. When several do, they are listed on screen with their descriptions, and nothing changes; say one of them, or add a feature. “Slash voice” alone lists all of them, described the same way.

From the shell, `claudio set voice` still takes a name.

“Slash voice” sets the voice of the mouth that speaks: the Aura voice with Deepgram, `elevenlabs_voice` with ElevenLabs, `local_voice` with Kokoro. “Slash elevenlabs voice” and “slash local voice” set theirs whichever mouth speaks.

The name is not checked against Deepgram's list. A voice Deepgram does not know leaves the mouth unable to connect, and you see `! mouth lost`. Deepgram's [text-to-speech models page](https://developers.deepgram.com/docs/tts-models) lists every voice.

## Switch the mouth to ElevenLabs

The ears are always Deepgram, so you still need a Deepgram key. Setup does not ask for the ElevenLabs key, so add it yourself:

<Steps>
<Step>

### Add the ElevenLabs key

Add it to `~/.config/claudio/secrets.json`, next to the Deepgram key:

```json title="secrets.json"
{ "deepgram_api_key": "your_deepgram_key", "elevenlabs_api_key": "your_elevenlabs_key" }
```

Or export it in the shell you start claudio from, then restart claudio:

```bash
export ELEVENLABS_API_KEY=your_elevenlabs_key
```

</Step>
<Step>

### Switch the mouth

```bash
claudio set mouth elevenlabs
```

A running claudio reloads the settings and the key from `secrets.json`, and the next reply speaks through ElevenLabs.

</Step>
<Step>

### Pick an ElevenLabs voice

By voice, say a name from your ElevenLabs voice library, or what you want, as for Aura: “slash voice Adam”, “slash voice a British woman” while ElevenLabs speaks, or “slash elevenlabs voice Adam” at any time. claudio reads the library when it starts, with each voice's accent, age, gender, style and use, and the words after its name, so `Adam - Dominant, Firm` is `dominant` and `firm`. One voice that fits becomes the voice; several are listed on screen.

From the shell, `elevenlabs_voice` takes the voice id, not a name. Copy it from the library:

```bash
claudio set elevenlabs_voice pNInz6obpgDQGcFmaJgB
```

</Step>
</Steps>

claudio streams from ElevenLabs' `eleven_flash_v2_5` model as 24 kHz PCM (`pcm_24000`).

If `mouth` is `elevenlabs` but no ElevenLabs key is set, Deepgram Aura speaks instead, with no warning. The banner shows which mouth started: `voice elevenlabs pNInz6ob` for ElevenLabs, `voice orion` for Aura. “slash status” always names the Aura voice, even while ElevenLabs speaks.

To go back to Aura:

```bash
claudio set mouth deepgram
```

## Speak with Kokoro, on your Mac

The local mouth runs [Kokoro](https://github.com/hexgrad/kokoro), an open voice model, on your Mac's CPU. It needs no key, and what claudio says never leaves the machine. The ears are still Deepgram, so you still need a Deepgram key.

<Steps>
<Step>

### Install Kokoro and espeak-ng

```bash
brew install espeak-ng
uv tool install --reinstall 'claudio[local] @ git+https://github.com/ActurialCapital/claudio'
```

</Step>
<Step>

### Switch the mouth

```bash
claudio set mouth local
```

The next start downloads the compressed voice model to `~/.config/claudio/models`, about 115 MB, once.

</Step>
<Step>

### Pick a voice and a speed

```bash
claudio set local_voice af_heart
claudio set local_speed 1.1
```

`local_voice` is a Kokoro voice name: the first letter is the accent (`a` American, `b` British), the second is female or male. `am_michael` is the default; `af_heart`, `am_fenrir`, `bf_emma` and `bm_george` are others worth trying. A name Kokoro does not know stops the start with the full list. By voice, the same features work as for Aura: “slash local voice British man” lists `bm_daniel`, `bm_fable`, `bm_george` and `bm_lewis`, and a feature only one voice has picks it. `local_speed` runs from `0.5` to `2.0`.

</Step>
<Step>

### Pick the compressed or the full model

```bash
claudio set local_model full
```

`compressed` is the default: 88 MB and about twice as fast. `full` is 325 MB and sounds a little cleaner. The first reply after a switch downloads the model if it is not there yet, then loads it; both stay on disk, so switching back is instant.

</Step>
</Steps>

Synthesis time on an M4, per sentence:

| Model | Short sentence | 70 characters |
|---|---|---|
| `compressed` | 0.2 s | 0.5 s |
| `full` | 0.5 s | 1.0 s |

Either way the first word comes a little later than with Aura. The banner shows `voice local am_michael`.

## What happens when the mouth fails

A reply is never lost. You read it as text instead:

- **The speech service cannot be reached**: claudio tries once more after one second. If that fails too, you see `! mouth lost: the speech service is unreachable; text only`, and the reply is shown as text.
- **The connection drops mid-reply**: claudio opens a new connection and carries on from the sentence it was on. If that fails, you see `! mouth lost mid-reply; the rest is text only`.

Each new reply tries the mouth again. [Troubleshooting](/docs/troubleshooting#mouth-lost) has the fixes.
