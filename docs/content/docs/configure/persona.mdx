title: Persona and style
description: Edit what the brain is told, and switch how it talks without touching it.
---

The brain's instructions are a plain Markdown file:

```text
~/.config/claudio/prompt.md
```

It is copied from the package on the first run. After that it is yours: edit it freely. When you save it, the brain restarts with the new persona and its memory kept, and says it is back.

## What the default persona says

The packaged persona sets out a few things. Keep them in mind when you edit:

- **Write for the ear.** Two to five short, plain sentences. No Markdown, lists, code, paths or URLs, since all of it is spoken.
- **Lead with the answer.** End with a question only when the next step is your call.
- **Say what it is about to do** in two to five words before any tool call, so you hear something while the tool runs: "Checking the roadmap."
- **Discuss or hand over.** Answer discussion itself, hand work to a session, and never do the work.
- **How to use cmux**: hand over with the agent inbox and the marker, list sessions, read a screen, open workspaces and splits.
- **How to narrate events**: finishes in plain words, permission prompts read out but never answered, choices read out numbered.
- **How to change settings** with `claudio set`.

### Placeholders

Two placeholders are filled in when the brain starts:

| Placeholder | Becomes |
|---|---|
| `{TRANSCRIPTS}` | the transcripts directory |
| `{KEYS}` | the names of the settings it may change |

After the persona, claudio appends the orchestrator, the current settings, and the list of open sessions with their surface ids and directories. You do not need to write those.

## Style

The `style` setting changes how it talks without editing the persona. It follows [claudish-to-english](https://github.com/gvzdv/claudish-to-english)'s idea of presets you can flip mid-session.

| Style | Sounds like |
|---|---|
| `plain` | the persona as written, two to five sentences |
| `brief` | one sentence per reply, two when the answer has two parts, no lead-in before a tool |
| `caveman` | at most six words a sentence, no articles, fragments; names and numbers stay exact |

<Transcript>{`
› slash style caveman
⚙ style → caveman  ·  brain restarting
◆ Back. Caveman now.
› what's left on the roadmap?
◆ Next: Sales. File fields still open. Main clean. Want Sales started?
`}</Transcript>

Switch by voice ("slash style brief"), by typing `/style brief`, or with `claudio set style brief`. The brain restarts with its memory kept.

<Callout>
To make a style permanent for one project only, put `{ "style": "brief" }` in that project's `.claudio.json`.
</Callout>
