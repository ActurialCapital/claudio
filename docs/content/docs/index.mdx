You talk. claudio answers in a sentence or two, or hands the work to one of your Claude Code sessions and tells you when that session is done, asks something, or needs a permission.

It is not a bot that reads your terminal aloud. A separate small brain talks with you, decides whether you are discussing or asking for work, and narrates what your sessions report back in plain words.

<Transcript>{`
› rebase 44 on main and run the tests
◆ Sending that to Sequencer.
  → cmux agent message

▸ Sequencer  done  ·  for "rebase 44 on main and run the tests"
◆ Rebased, tests pass, nothing to fix.

▃ listening  ·  1.1 s to first word  ·  Sequencer idle
`}</Transcript>

## The parts

claudio has three parts, and your sessions sit beside them.

- **Ears.** Deepgram Flux turns your speech into text as you talk and decides when your turn has ended.
- **Brain.** One long-lived `claude -p` process with a short persona. It answers questions itself and hands work to a session. It never does the work.
- **Mouth.** Deepgram Aura, or ElevenLabs, speaks the brain's reply one sentence at a time.
- **Your sessions.** Ordinary Claude Code sessions in cmux workspaces. Work reaches them through cmux's agent inbox. They report back through three Claude Code hooks.

## What you need

- macOS. The echo canceller is Apple's voice-processing unit, and cmux is a Mac app.
- [cmux](https://cmux.dev), with the workspace you want to send work to.
- [Claude Code](https://claude.com/claude-code), signed in. The brain runs on your Claude plan.
- A [Deepgram](https://console.deepgram.com) API key, for the ears and the default mouth.
- Python 3.11 or later and [uv](https://docs.astral.sh/uv/).
- Optional: the Xcode command line tools, so you can talk over it on speakers.
