title: Getting started
description: Install claudio, answer the setup questions, and check everything with the doctor.
---

Install claudio, answer a few setup questions, and run the doctor to confirm every part works. Check [what you need](/docs#what-you-need) first, and pick where your sessions live: the `backend` setting, `cmux` by default or `bb`. Anything specific to your platform is on its page: [bb](/docs/platforms/bb) or [cmux](/docs/platforms/cmux).

<Steps>
<Step>

### Install claudio

```bash
uv tool install git+https://github.com/ActurialCapital/claudio
```

This puts a `claudio` command on your path.

</Step>
<Step>

### Choose where your sessions live

For bb threads, set the backend, then run setup yourself (setting it counts as a first run, so `claudio` alone would skip setup):

```bash
claudio set backend bb
claudio setup
```

For cmux panes, skip this: `cmux` is the default. [Platforms](/docs/platforms) compares the two.

</Step>
<Step>

### Run it from a project

```bash
cd ~/code/myproject
claudio
```

The brain runs in the directory you start claudio from and reads files there when a question needs facts. A `.claudio.json` in that directory can [override settings](/docs/configure/settings#change-a-setting) for that project.

</Step>
<Step>

### Answer the setup questions

The first run starts a short setup. It checks that `claude` is installed, and the sessions' platform that `backend` names, marking each with ✓ or ✗, then asks for:

1. **Your Deepgram key**: tested against Deepgram before it's saved. You get three tries
2. **The orchestrator**: the session that gets your tasks by default, picked by number from the ones the platform has open: cmux's workspaces or bb's threads. If none is listed, you type its title
3. **A voice**: one of six Aura-2 voices. Any other Aura-2 voice works later with `claudio set voice`
4. **The brain's model and effort**: press <kbd>Enter</kbd> to keep `default` and `low`
5. **The transcript layout**: `inline`, or `split` with your turns on the right
6. **Barge-in**: whether talking over claudio pauses it

Settings go to `~/.config/claudio/config.json` and the key to `secrets.json` beside it, readable only by you. Run `claudio setup` to answer the questions again.

</Step>
<Step>

### Install the hooks

Setup then offers to add three hooks to `~/.claude/settings.json`: `Stop`, `Notification`, and `PreToolUse` for `AskUserQuestion`. Your sessions use them to report back, so answer yes.

Your other settings stay as they are, and the previous file is copied to `settings.json.bak-claudio` first. If `settings.json` is a symlink, the file it points to is the one updated. If the file isn't valid JSON, claudio changes nothing and tells you why.

Add or remove the hooks any time with `claudio install` and `claudio uninstall`.

<Callout type="warn">
A Claude Code session loads its hooks when it starts. Restart any session that was already running, or it won't report back.
</Callout>

</Step>
<Step>

### Check everything

```bash
claudio doctor
```

The doctor checks each part in this order. The two lines after the version are for the platform `backend` names; these are cmux's, and with `bb` they read `bb reachable` and `orchestrator '…' is a bb thread`:

```transcript
  ✓ claude on PATH
  ✓ claude version 2.x.x (Claude Code)
  ✓ cmux reachable
  ✓ orchestrator 'Sequencer' is a live workspace
  ✓ Deepgram key set
  ✓ Deepgram key accepted
  ✓ the three Claude Code hooks installed
  ✓ echo canceller built or buildable
  ✓ microphone: MacBook Pro Microphone
  ✓ persona prompt present
```

A failed check shows ✗ and a hint beside it. [Troubleshooting](/docs/troubleshooting) covers each one.

The doctor then runs one typed turn through the brain and the mouth, and you hear "the doctor is in." It finishes with `all good`, or `fix the ✗ lines above`.

</Step>
</Steps>

## Have your first conversation

Run `claudio` again. On the first start it builds the echo canceller, once, if the Xcode command line tools are installed. It then prints its [banner](/docs/guide/on-screen#read-the-banner), and the state line reads `warming up the brain…`, then `listening`.

Ask a question about the project, then ask for some work and watch the orchestrator pick it up:

```transcript
› what's on the roadmap for this week?
◆ Checking the roadmap.
  → reading ROADMAP.md
◆ Two things: the export screen and the retry logic for uploads.

› have Sequencer do the retry logic
◆ May I send "do the retry logic for uploads" to Sequencer?
› yes
◆ Sending that to Sequencer.
```

Press <kbd>Enter</kbd> to cut a reply and <kbd>Ctrl</kbd>+<kbd>C</kbd> to quit. To see and type to claudio in bb's panel instead of a terminal, [install the bb plugin](/docs/platforms/bb#install-the-plugin). Next, learn [how to talk to it](/docs/guide/talking).
