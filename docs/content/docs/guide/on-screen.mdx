claudio is meant to be heard, but the terminal keeps a written record that stays in time with the voice.

## The banner

When claudio starts it prints the wordmark and one line of facts:

<Transcript>{`
  orchestrator Sequencer  ·  brain default/low  ·  voice orion  ·  echo cancel on  ·  memory on
  Enter cuts · Ctrl-C quits · claudio setup
`}</Transcript>

`echo cancel off` means you need headphones to talk over it. `memory fresh` means this is a new conversation.

## The transcript

Each line starts with a glyph that says who it is from.

| Glyph | Line |
|---|---|
| `›` | you |
| `◆` | claudio |
| `▸` | a session reporting back, with the request it was for |
| `→` | what the brain is reading or running |
| `⚙` | a setting you changed |
| `·` | a note: cut, resumed, muted, reconnecting |
| `!` | a warning |

Room noise and backchannels ("mm-hm") show dim, as do turns that did not start with "claudio" when `address_me` is on.

A few details:

- **Sentences appear as they are spoken.** Each sentence is printed when its audio starts playing, so the text never runs ahead of the voice.
- **Lines wrap at 90 columns**, however wide the pane.
- **A dim rule with the time** marks a gap of more than five minutes between turns.

<Transcript>{`
› what's the sequencer doing?
  → cmux read-screen
◆ Sequencer is halfway through the migration tests.
  Twelve pass, two are still running.
· cut
› mm-hm
⚙ voice → thalia
! slow: 3.4 s to first word
`}</Transcript>

## The state line

The last line of the terminal is live. From left to right:

1. **A mic level bar**, `▁` to `▇`.
2. **What claudio is doing**: `listening`, `thinking`, `speaking`, `paused`, `muted · say /unmute`, `ears lost · reconnecting`, or `push to talk · Enter opens the mic`.
3. **How long the last reply took to its first word**, shown for a few seconds after each reply.
4. **What the orchestrator is up to**: `working`, `waiting on you` or `idle`.

<Transcript>{`
▃ listening  ·  1.1 s to first word  ·  Sequencer idle
`}</Transcript>

## Transcripts

Every conversation is kept as Markdown, one file a day:

```text
~/.config/claudio/transcripts/2026-10-25.md
```

Each line has the time and the same glyphs as the screen:

```text
14:02  › rebase 44 on main and run the tests
14:02  ◆ Sending that to Sequencer.
14:05  ▸ Sequencer  done  ·  for "rebase 44 on main and run the tests"
14:05  ◆ Rebased, tests pass, nothing to fix.
```

Ask "what did we do today?" or "what did I ask yesterday?" and the brain reads that day's file and answers from it, in order.
